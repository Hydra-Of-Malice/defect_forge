## Faint-defect lift (hardest three severity levels)

- Spec only: 72/141 detected; with 8 forged examples: 59/141 (exact McNemar p = 0.0106): a significant DROP. Full-strength examples raised the inspector's bar, so it dismissed more faint defects. In-context exemplars are not free; measure them before deploying.

## Blind spot found and fixed: white print (eval/blind_spot.py, not pre-registered)

Exploratory (not pre-registered). On the real benchmark, every spec-only miss was WHITE print mistaken for gloss. Bold forged white print was caught 12/12, so forging alone did not reproduce the subtle real misses. But two forged white-print EXAMPLES in context fixed the real blind spot (real print 12/17 -> 17/17, paired exact p = 0.0625; 0/40 false alarms), while generic black-ink examples (C2) made it worse. A one-clause spec amendment also fixed it, with 1/40 false alarms.

| Measurement | Detected |
|---|---|
| Real white print, original spec | 12/17 |
| Forged white print, original spec (reproduces the blind spot?) | 12/12 |
| Forged white print, amended spec | 12/12 |
| Real white print, amended spec (fix transfers to real parts?) | 17/17 |
| False alarms on real good parts, amended spec | 1/40 |
| Real white print, original spec + 2 forged white-print examples | 17/17 |

Spec amendment tested: "4.5 Clarification: bright white or light-coloured characters, letters, digits or ink smudges on the shell are PRINT (4.4) and must be rejected. Do not dismiss them as gloss or specular highlights: natural gloss is a smooth soft highlight that follows the shell curvature and never forms characters or sharp-edged marks."
