## White-print blind spot (R2)

Real print is the inspector's weakest real defect: white print is read as gloss. Bold forged white print was caught 12/12, so forging did not reproduce the real misses. Under the rule fixed in advance, the forged white-print examples earn no credit: forged examples alone vs spec only gave p = 1.0. This replaces our earlier claim, which was confounded because that run also contained 2 good photos.

## Notes

- Curves: a variant counts as caught when the inspector's box overlaps the defect in at least 2 of 3 passes. All 3 passes agreed on 86% of 385 variants.
- False-alarm control: 3/48 inspections of unedited source parts were flagged (16 parts, 3 passes). 46 variants were flagged in the wrong place.
- Real benchmark over 3 passes: recall 95.5%, 93.9%, 97.0%; specificity 100.0%, 100.0%, 100.0%.
- Faint-defect check: spec-only passes flagged 70, 74, 73 of 141; the single forged-examples pass flagged 59 (exact McNemar p = 0.0347, 0.0015, 0.0066).
- Tiny defects: for shrunken holes and prints the inspector's box often misses by 0.2-0.5 mm. It notices them but can't pinpoint them; see the box-accuracy table (a post-hoc check, not pre-registered).
- Revalidation spend: $6.45 of Meta API calls.
- Benchmark: MVTec AD hazelnut test split, 66 defective + 40 good scored (4 oracle images held out).
- In-context C2 vs C1: exact McNemar p = 0.2188.
- Faint-defect test (hardest 3 severity levels, 141 images): spec only 72 vs with 8 forged examples 59 detected, exact McNemar p = 0.0106: a significant drop: with forged examples in the prompt, the inspector flagged fewer faint defects. The cause is untested; one guess is that full-strength examples raise its bar.
- Equivalent diameters in mm assume the spec's 20 mm nominal hazelnut width.
- Total Meta API spend for this evaluation (all stages, cumulative across resumed runs): $4.85.

## Deviations from EVAL.md

- 2 of the 60 forgeries failed on the API's transient 404 before the retry fix landed, and the critic rejected 3 cracks, leaving 12-15 accepted per type against a target of 15.
- The single-pass curves, which counted any defect claim as caught, were replaced as the headline by the located 3-pass curves (addendum R1, committed before those runs). The originals are kept in `eval.json` as `curves_first_pass`.
- Our first white-print conclusion was confounded and is withdrawn; R2 replaces it.
- The white-print experiment itself was added after seeing the real misses, so it is exploratory.
- The box-accuracy table was added after seeing the located curves, so it is post-hoc. The headline stays the pre-registered overlap measure.
- The faint-defect comparison repeats the spec-only side three times, but the forged-examples side was run once.
- Part masks now come from a Muse Spark box into SAM 3.1. The evaluated forgeries used the earlier point-prompt masks.
